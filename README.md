# proj_3006_SimpleHeatmap

ดึงราคา **bid/ask** ปัจจุบันจาก MetaTrader 5 ของทุก symbol ที่ระบุไว้ในแถวที่ 1 ของ
Google Sheet แล้ว **append** ต่อท้ายเป็นแถวใหม่ 1 แถวต่อการรัน 1 ครั้ง
(ตั้งเวลาไว้ทุกวันทำการ 10:00 น. เวลาไทย) เพื่อสะสมข้อมูลไว้ทำ heatmap

Sheet: `1MmAn7aVFIdReaMZgxoN-thw-LMtBFna4B5qCKI8kNpU`

## Sheet layout (worksheet `Data`)

|       | A          | B        | C        | D       | E        | F       |
|-------|------------|----------|----------|---------|----------|---------|
| แถว 1 | Date       | Time     | XAUUSD.s |         | CMX.GCV6 |         |
| แถว 2 |            |          | BID      | ASK     | BID      | ASK     |
| แถว 3 | 2026-09-04 | 10:00:01 | 4474.12  | 4474.60 | 4485.50  | 4485.90 |

- **แถว 1 คือ config** — คอลัมน์แรก ๆ ที่ชื่อ `Date` / `Time` / `Timestamp` คือบล็อกเวลา
  ส่วนที่เหลือคือชื่อ symbol โดยแต่ละตัวกิน 2 คอลัมน์ (BID, ASK)
  เพิ่ม/ลด/สลับ symbol ทำที่ sheet อย่างเดียว ไม่ต้องแก้โค้ด
- แถว 2 (BID/ASK) สคริปต์เขียนให้เองอัตโนมัติถ้ายังไม่มี
- ข้อมูลเริ่ม append ที่แถว 3 เสมอ
- **Timestamp คือเวลา snapshot ที่ตั้งไว้ (10:00:00) ไม่ใช่เวลาที่รันสคริปต์** — สคริปต์ดึง
  tick ตัวสุดท้าย ณ หรือก่อน 10:00 พอดี ผ่าน `copy_ticks_range` ดังนั้นรันกี่โมงก็ได้ผลเท่าเดิม
  (idempotent) และย้อนหลังได้
- Timestamp เป็น **เวลาไทย (GMT+7)**; MT5 เดินด้วย GMT+0 — เวลาของ tick จริง (UTC)
  ถูกบันทึกไว้ในไฟล์ log เพื่อใช้ตรวจว่าราคาค้าง (stale) หรือไม่
- symbol ไหนดึงราคาไม่ได้จะเว้นเซลล์ว่างไว้ (ไม่ใส่ 0)

## Tab `Front` — carry heatmap

แถว = วันที่, คอลัมน์ = contract, ค่าในช่องคือ **annualized cash-and-carry**

```
carry = (fut_BID / spot_ASK - 1) x 365 / (TTM - วันที่ของแถว)
```

ใช้ราคาฝั่งที่ทำได้จริง — ซื้อ spot ที่ ASK ขาย futures ที่ BID

- เป็น**สูตรล้วน** อ่านจาก `Data` โดยตรง เพิ่มแถวใหม่/backfill แล้วขึ้นเอง ไม่ต้องรันอะไร
- **หัวคอลัมน์ดึงจาก `Data` แถว 1 อัตโนมัติ** — symbol ที่มี TTM = contract (ได้คอลัมน์),
  symbol ที่ไม่มี TTM = spot (เป็นตัวหาร) เพิ่ม contract ที่ `Data` แล้ว `Front` โตเอง
- **สีล็อกไว้ 0%–6%** ตายตัว ค่านอกกรอบตัดสีที่ปลาย ไม่ปรับตามข้อมูล
  เพื่อให้เทียบข้ามวันได้จริง
- ตั้งค่าครั้งเดียวด้วย `uv run python setup_front.py` (รันซ้ำได้ ไม่ซ้อนทับ)

### ⚠️ เวลา contract หมดอายุ ให้ append คอลัมน์ใหม่ ห้ามแทนที่ของเดิม

TTM อยู่ในแถว 1 = เซลล์เดียวที่ทุกแถวใช้ร่วมกัน ถ้าเอา contract ใหม่ไปทับคอลัมน์เดิม
**ประวัติทั้งคอลัมน์จะถูกคำนวณใหม่ด้วย TTM ตัวใหม่** — ตัวอย่างจริง แถว 2026-09-04
ของ `GOU26` จะเปลี่ยนจาก 4.94% เป็น 1.07% ทั้งที่ราคา bid ในแถวนั้นไม่ขยับเลย
และ `Data` ก็ไม่เหลือร่องรอยว่าคอลัมน์นั้นเคยเป็น contract อะไร

ให้ปล่อย contract เก่าค้างคอลัมน์ไว้ (ช่องจะว่างเองหลังหมดอายุ) แล้วเติมตัวใหม่ต่อขวาสุด

## Permission ที่ต้องมี

| ชั้น | สิ่งที่ต้องมี |
|---|---|
| Google OAuth scope | `https://www.googleapis.com/auth/spreadsheets` |
| Credential | `..\.cred\client_secret.json` + `..\.cred\authorized_user.json` (ใช้ร่วมกับ proj_3003/3004) |
| สิทธิ์บน Sheet | บัญชี Google ของ `authorized_user.json` ต้องเป็น **Editor** ของสเปรดชีตนี้ |
| MT5 | terminal ต้องเปิดและ **ล็อกอินค้างไว้** (ต่อแบบ `mt5.initialize(path=...)` ไม่มี login/password) และ symbol ต้องอยู่ใน Market Watch |
| Windows | Task Scheduler รันภายใต้ user ที่ล็อกอินอยู่ (`InteractiveToken`) |
| ครั้งแรก | ถ้า token หมดอายุ/refresh ไม่ได้ ต้องรันแบบมี console 1 ครั้งเพื่อทำ OAuth ผ่านเบราว์เซอร์ |

**ไม่ต้องใช้:** service account, API key, Drive scope, MT5 investor/master password

## กรณีข้ามวัน (เครื่องปิด / task ไม่ได้รัน / MT5 ไม่เปิด)

**ไม่ต้องทำอะไร — รอบถัดไปเก็บย้อนให้เอง** สคริปต์ดูวันที่ล่าสุดในคอลัมน์ A แล้วไล่เก็บ
snapshot 10:00 ของ **ทุกวันทำการที่ยังขาด** จนถึงวันนี้ เขียนรวดเดียวเรียงตามวัน

- **กันเขียนซ้ำ** — วันที่ที่มีอยู่แล้วในชีตจะข้าม รันกี่รอบก็ไม่เกิดแถวซ้ำ
  (ดังนั้นรันมือแทรกระหว่างวันได้ปลอดภัย)
- **เสาร์-อาทิตย์ / วันหยุดตลาด** — ข้ามอัตโนมัติ (เสาร์อาทิตย์ข้ามตามปฏิทิน,
  วันหยุดอื่นข้ามเพราะไม่มี tick เลย) ไม่เขียนแถวว่าง
- **`max_backfill_days`** (ค่าเริ่มต้น 10) จำกัดว่าย้อนได้ไกลสุดกี่วัน กันกรณีหายไปนาน ๆ
  แล้วไปดึงเกินช่วงที่ MT5 ยังเก็บ tick history ไว้ (เท่าที่ทดสอบย้อนได้อย่างน้อย 60 วัน)
- ถ้าหายไปนานกว่านั้นและอยากได้ครบ ค่อยเพิ่ม `max_backfill_days` หรือใช้ `--date` ไล่ทีละวัน

> ข้อควรระวัง: `--date` เขียนต่อท้ายเสมอ ถ้าใช้ backfill วันเก่ากว่าแถวล่าสุด
> ลำดับแถวในชีตจะไม่เรียงตามวันที่ (ข้อมูลถูก แต่ต้อง sort เองถ้าจำเป็น)

ตั้ง scheduled task (ทุกวันจันทร์–ศุกร์ 10:00):

```bash
schtasks /create /xml SimpleHeatmap_task.xml /tn SimpleHeatmap
```

ยิงทดสอบทันที:

```bash
schtasks /run /tn SimpleHeatmap
```

## Config

`config.json` — `spreadsheet_id`, `sheet_name` (เว้นว่าง = ใช้ชีตแรก), `log_file`,
`snapshot_time` (เวลาที่ต้องการ snapshot, เวลาไทย), `lookback_minutes`
(ย้อนหาราคาถอยหลังได้กี่นาที — ตั้งไว้ 3 นาที ถ้าเกินนั้นเว้นว่าง เพราะต้องการให้ทุก
symbol อยู่ ณ เวลาเดียวกันจริง ๆ), `max_backfill_days` (ย้อนเก็บวันที่ขาดได้ไกลสุดกี่วัน),
`timezone`

`MT5_PATH` อ่านจาก `..\.env\Path.env` ที่ใช้ร่วมกันทั้ง repo

Log: `logs/simple_heatmap.log` (rotate 1 MB × 5)
